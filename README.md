# limits-card

Мод для Claude Code: тонкая карточка лимитов в боковой панели.

- **5 часов** и **Неделя**: сколько процентов окна использовано и через сколько оно сбросится.
- **Контекст**: сколько токенов занято и на какой отметке мод `ctx-handoff` передаст дела в новую сессию.
- Кнопки **«Очистить контекст»** (запускает `/handoff now`) и **«Новый диалог»** (сохраняет записку о передаче дел и открывает новый чат с ней).

Карточка открывается сама при старте сессии. Команды:

- `/limits` — показать или скрыть карточку.
- `/newchat` — записка о передаче дел и новый диалог с ней.

Кнопки и `/newchat` работают, когда установлен мод [ctx-handoff](https://github.com/cablate/ctx-handoff-mod). Без него карточка просто показывает лимиты.

## Установка

В Claude Code, в строке ввода:

```
/plugin install limits-card --marketplace Silva2122/limits-card
```

На вопрос о добавлении маркетплейса ответьте `y`, затем выберите область (обычно «user»). После перезапуска сессии карточка появится в панели.

То же из обычного терминала:

```bash
claude plugin install limits-card --marketplace Silva2122/limits-card
```

## Настройка

В настройках плагина есть одно поле, `handoffAt`: число токенов контекста, на котором `ctx-handoff` передаёт дела (по умолчанию 300000). Укажите то же значение, что и в `threshold` у ctx-handoff, тогда полоска «Контекст» будет показывать путь до передачи точно.

## Разработка

Папку можно подключить напрямую, без установки:

```bash
claude --plugin-dir /путь/к/limits-card
```

Исходники: `hooks/register.tsx` (хуки и панель), `hooks/card.ts` (рисунок карточки в SVG), `hooks/newchat.ts` (новый диалог с запиской), `types/index.d.ts` (контракт состояния). Тесты лежат в `tests/`.
